# 🎁 GiftGenie AI — Cinematic AI-Powered Gift Recommendation Platform

GiftGenie AI is a state-of-the-art, cinematic AI shopping and gift recommendation web application designed for Indian marketplaces (Amazon, Flipkart, Myntra, Nykaa, AJIO, Croma, and Reliance Digital).

![GiftGenie AI](https://images.unsplash.com/photo-1549465220-1a8b9238cd48?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **🎬 3D Cinematic Hero Experience**: Unfold-inspired 3D animated floating card streams with mouse parallax depth, live ticker, and platform integration.
- **🌌 7-Step Context-Reactive Wizard**:
  1. **Recipient**: 15 archetype cards with emotional taglines.
  2. **Occasion**: 20 celebration milestones (Wedding, Birthday, Diwali, Christmas, etc.).
  3. **Persona / Style**: Segmented modern aesthetic cards (Male, Female, Non-binary, Prefer not to say).
  4. **Age Timeline**: Dynamic life stage spotlight (`Toddler`, `Kid`, `Teen`, `Gen Z`, `Young Pro`, `Prime`, `Golden`).
  5. **Budget Spectrum**: Dynamic value tier engine (`Pocket-Friendly`, `Sweet Spot`, `Premium`, `Luxury Elite`).
  6. **Passions & Interests**: 28 interest tags with category filter tabs and real-time AI Gift Match Radar.
  7. **Store Nexus**: Branded marketplace selectors with official brand logos and perks.
- **✨ Real-Time GPU-Accelerated Particle & Light Engine**:
  - Volumetric sweeping caustic light rays.
  - Floating soft bokeh discs with breathing harmonic cycles.
  - Specular stardust particles with 4-point lens flare cross-glints.
  - Smooth 60-frame color lerping that reacts in real-time to user selections.
- **⚡ Neural Noise Video Results Canvas**: Cinematic high-definition looping video background with subtle luxury grading.
- **🎯 Verified 75-Product Catalog**: Strictly calibrated interest matching across Indian eCommerce platforms.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/giftgenie-ai.git

# Navigate to project directory
cd giftgenie-ai

# Install dependencies
npm install

# Start local dev server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Build for Production

```bash
npm run build
```
